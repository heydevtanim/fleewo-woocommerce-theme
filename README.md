# Fleewo — WordPress & WooCommerce Fashion Store

![Fleewo homepage and shop preview](screenshots/homepage.jpg)

A responsive, multi-category fashion storefront theme concept for Fleewo, built for WordPress and WooCommerce. This repository presents the theme source, project screenshots, and an installable theme ZIP.

## Project overview

Fleewo is a modern fashion and accessories e-commerce experience covering Men, Women, Kids, Accessories, and Lifestyle. The design focuses on clear product discovery, readable product details, and a consistent shopping flow across desktop and mobile.

## Highlights

- Responsive layouts for homepage, shop, product, cart, and account pages
- WooCommerce theme integration
- Category discovery for five collections
- Neutral palette: Obsidian Black, Porcelain White, Warm Sand Beige, and Soft Silver Gray
- Mobile-friendly navigation and shopping controls

## Install the theme

1. In WordPress Admin, open **Appearance → Themes → Add New → Upload Theme**.
2. Select `release/fleewo-woocommerce-theme-v1.0.0.zip` and click **Install Now**.
3. Activate the theme.
4. Install and activate WooCommerce to enable store, cart, and checkout functionality.
